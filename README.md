# Abstract-Factory
Абстрактная фабрика — это порождающий паттерн проектирования, который позволяет создавать семейства связанных объектов, не привязываясь к конкретным классам создаваемых объектов.
(из книги "Погружение в паттерны проектирования")

Обладает следующими характеристиками:
Тип:  порождающий

Принцип работы:

Общий интерфейс (Abstract Factory) - его конкретные реализации.
Интерфейс продуктов - конкретные реализации продуктов для конкретных фабрик
Код вызывает фабрику.


Назначение: 
Создавать семейства взаимосвязанных объектов, не указывая их конкретные классы.

 Обеспечить единообразный интерфейс для создания целых семейств продуктов.

 Абстрагировать создание продуктов от остальной части приложения.
Метафора: Завод, производящий автомобили всех марок. Абстрактная фабрика будет представлять интерфейс для создания автомобилей. 
Конкретные фабрики будут представлять различные производственные линии, производящие различные марки и модели автомобилей. Например, есть ГАЗ-АА (грузовик) и ГАЗ-М1 (легковой автомобиль), а также Mercedes-грузовик и Mercedes-легковой автомобиль.
Клиентский код будет представлять покупателей автомобилей, которые могут взаимодействовать с абстрактной фабрикой, чтобы получить желаемый автомобиль без необходимости знать детали производственного процесса. То есть если клиент скажет "дайте мне грузовик и легковую  ГАЗ", то он получит  машины соответствующих марок и комплектации.
Потенциальные проблемы: Код программы сильно усложняется из-за введения дополнительных классов. При попытке добавить новый элемент требуется добавить его в интерфейс фабрики, и в конкретную реализацию.

Отличия от Factory Method:

В отличие от паттерна Factory Method, который создает отдельные объекты, паттерн Abstract Factory создает семейства взаимосвязанных объектов. Кроме того, в Abstract Factory используются конкретные фабрики, которые создают все объекты в семействе, тогда как в Factory Method используется один конкретный класс-создатель.
